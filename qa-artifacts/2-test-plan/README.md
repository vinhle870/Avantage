# 2 — Test Plan

This folder holds the formal plan for the test cycle: what will be tested, how,
by whom, and the conditions under which testing may start and stop.

**Filled in by:** the `stlc-test-plan-designer` skill.
**Output file:** `test-plan.md`

The generated plan follows IEEE 829 structure and covers:

- Test objectives, and the scope of what is in and out.
- The test strategy and the test types that will be applied.
- Entry criteria (when testing may begin) and exit criteria (when it is done).
- The environment and the test data the cycle depends on.
- A risk and mitigation table.
