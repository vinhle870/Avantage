| **Route** | autoShield contract page (URL recorded by AP2225_009) |
| **Type** | Functional |

**Why this matters:** The PDF is the document the client receives. The developer noted on 2025-04-22 that AutoShield's link downloads the file instead of opening it, and the ticket does not say which is wanted (Q-009), so this case checks only that a PDF of this contract is delivered.

| Variable | Value |
|---|---|

| # | Action | Expected Result |
|---|---|---|

| 3 | Click the PDF link | A PDF opens in a tab or is downloaded; no error page. Record which for Q-009 and the file name if downloaded |
| 4 | [Verification] Verify the delivered document is a PDF and, where its text can be read, that it shows the client `QA AP2225-A-…` or the contract ID from AP2225_009 | The document is a PDF. An empty file, an HTML error page or a document for another client or contract is a FAIL |
