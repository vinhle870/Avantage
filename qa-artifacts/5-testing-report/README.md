# 5 — Testing Report

This folder holds the deliverables that leave the QA team — the documents a
release manager or product owner reads to decide whether to ship.

**Filled in by:** the `stlc-bug-reporter` and `stlc-test-reporter` skills.
**Output files:** `bug-report.md` and `test-report.md`

- **bug-report.md** — every defect found this cycle, with severity, priority,
  reproduction steps, evidence, and the tracker ticket link created for it.
- **test-report.md** — the executive report: overall verdict
  (PASS / CONDITIONAL PASS / FAIL), execution and defect metrics, requirement
  coverage, known limitations, and the sign-off checklist.
